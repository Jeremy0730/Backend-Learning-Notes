# Policy

The `Writer` policy requires an authenticated principal whose `role` claim is `writer`. POST, PUT, PATCH, and DELETE sit on a group with that policy. A missing or unknown key is 401. A reader key is 403. A writer key enters the endpoint.

```csharp
options.AddPolicy("Writer", policy =>
    policy.RequireAuthenticatedUser()
        .RequireClaim("role", "writer"));

var writes = weather.MapGroup("").RequireAuthorization("Writer");
```

`HandleChallengeAsync` writes 401 and `{ "error": "a valid X-Api-Key is required." }`. `HandleForbiddenAsync` writes 403 and `{ "error": "this key cannot change forecasts." }`. The body does not include the header value.

Authorization runs before `TemperatureFilter`. A writer key with temperature `100` passes the policy and then the filter returns 400. `store.Save` does not run.

| Request | Result |
| --- | --- |
| `POST` with no `X-Api-Key` | 401. The filter does not run |
| `POST` with `X-Api-Key: wrong-key` | 401. The filter does not run |
| `POST` with `X-Api-Key: reader-key` | 403. The filter does not run |
| `POST` with `writer-key` and `"temperatureC": 100` | 400 from `TemperatureFilter`. The list is unchanged |
| `POST` with `writer-key` and `"temperatureC": 25` | 201. `store.Save` runs |
| `DELETE /weatherforecast/2026-10-05` with `writer-key` | 204 |

Set a breakpoint in `HandleChallengeAsync`, and another on the first line of `InvokeAsync` in `TemperatureFilter`. Send the POST with no key. The challenge runs. `InvokeAsync` does not hit. Send the writer POST with temperature `100`. The challenge does not run. `InvokeAsync` returns 400.
