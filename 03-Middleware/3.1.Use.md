# Use

A request reaches the pipeline before it reaches an endpoint. `app.Use` registers one middleware. `await next(context)` runs the rest of the pipeline, including the matched `Map*` lambda. The lines after `await next` run when that lambda has returned.

```csharp
app.Use(async (HttpContext context, RequestDelegate next) =>
{
    var method = context.Request.Method;
    var path = context.Request.Path.Value ?? "/";
    context.Response.Headers.Append("X-Request-Path", path);
    await next(context);
    var status = context.Response.StatusCode;
    app.Logger.LogInformation("{Method} {Path} finished with {Status}", method, path, status);
});
```

This call sits above the `Map*` registrations. The framework runs each middleware in that order. `method` and `path` are available before the endpoint runs. `Path` does not include the query string, so `GET /weatherforecast?days=2` has path `/weatherforecast`.

The header is written before `next`. After the endpoint starts the body, the headers are already committed, so a header set on the lines after `await next` would not be sent. `status` is read after `next` because the endpoint sets it.

`GET /weatherforecast?days=2` does not take a `WeatherForecastStore`. The middleware still runs. `POST /weatherforecast` runs the same middleware, then the lambda asks the container for the store.

| Request | Header | After `next` |
| --- | --- | --- |
| `GET /weatherforecast?days=2` | `X-Request-Path: /weatherforecast` | Status 200. The lambda did not ask for the store |
| `POST /weatherforecast` with a valid body | `X-Request-Path: /weatherforecast` | Status 201. `store.Save` has already run |
| `GET /weatherforecast/2026-01-01` when that date was never stored | `X-Request-Path: /weatherforecast/2026-01-01` | Status 404 |

Set a breakpoint on `var method`. Send `GET /weatherforecast?days=2`. `path` is `/weatherforecast`, and the `MapGet` lambda has not run. Step into `await next`: the lambda runs and returns 200. Step back to `var status`: it is 200. The console log line is the same method, path, and status.
