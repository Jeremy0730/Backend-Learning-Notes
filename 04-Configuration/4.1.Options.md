# Options

`builder.Services.Configure<WeatherSettings>(builder.Configuration.GetSection("Weather"))` binds one section. The container supplies `IOptions<WeatherSettings>` to any endpoint that declares it.

```csharp
builder.Services.Configure<WeatherSettings>(builder.Configuration.GetSection("Weather"));

app.MapGet("/weatherforecast", (int days = 5, IOptions<WeatherSettings> settings) =>
{
    var weather = settings.Value;
    if (days < 1 || days > weather.MaxDays)
    {
        return Results.BadRequest(new { error = $"days must be between 1 and {weather.MaxDays}." });
    }

    var forecast = Enumerable.Range(1, days).Select(index =>
        new WeatherForecast
        (
            DateOnly.FromDateTime(DateTime.Now.AddDays(index)),
            Random.Shared.Next(-20, 55),
            weather.Summaries[Random.Shared.Next(weather.Summaries.Length)]
        ))
        .ToArray();
    return Results.Ok(forecast);
});
```

`settings` is not in the request. The parameter name can change and the same object is still passed in. `Value` is the bound `WeatherSettings`. Each property initializer on the class applies only when that key is missing. The `http` profile is Development, so `MaxDays` is `7`. `4.2.Environment` follows that value to `appsettings.Development.json`. `Summaries` still has the ten labels from `appsettings.json`.

`IOptions<WeatherSettings>` lives for the process. The next request receives the same `Value`. Editing a json file while the process is running leaves `Value` as it was. The next run reads the files again.

POST, PUT, and PATCH take the same `IOptions<WeatherSettings>` and compare `temperatureC` with `MinTemperatureC` and `MaxTemperatureC`.

| Request | Result |
| --- | --- |
| `GET /weatherforecast?days=2` | 200. Two forecasts. Each `summary` is one of the configured labels |
| `POST` with `"temperatureC": 100` | 400. `{ "error": "temperatureC must be between -90 and 60." }`. The list is unchanged |
| `POST` with `"temperatureC": 25` | 201. The limits came from `WeatherSettings` |

Set a breakpoint on `var weather = settings.Value`. Send `GET /weatherforecast?days=2`. `weather.MaxDays` is `7`. `weather.Summaries` has 10 entries. Send the same GET again. The breakpoint runs again, and `weather` is the same object.
