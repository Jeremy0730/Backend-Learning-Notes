# Environment

`CreateBuilder` loads `appsettings.json` first and `appsettings.Development.json` second. The same key in the second file replaces the first. A key that the second file leaves out stays as it was.

`appsettings.json`:

```json
"Weather": {
  "MaxDays": 14,
  "MinTemperatureC": -90,
  "MaxTemperatureC": 60,
  "Summaries": [ "Freezing", "Bracing", "Chilly", "Cool", "Mild", "Warm", "Balmy", "Hot", "Sweltering", "Scorching" ]
}
```

`appsettings.Development.json`:

```json
"Weather": {
  "MaxDays": 7
}
```

The `http` profile sets `ASPNETCORE_ENVIRONMENT` to `Development`, so this run uses both files. `MaxDays` is `7`. `MinTemperatureC` is still `-90`, because the Development file has no `MinTemperatureC` key. The Development file leaves the rest of the `Weather` section in place.

The default argument `days = 5` is inside `1..7`, so `GET /weatherforecast` with no query string returns 200.

| Request | Result |
| --- | --- |
| `GET /weatherforecast?days=7` | 200, JSON array of 7 items |
| `GET /weatherforecast?days=8` | 400, `{ "error": "days must be between 1 and 7." }` |
| `POST` with `"temperatureC": -20` | 201. `-20` is inside `-90..60` from `appsettings.json` |

Set a breakpoint on `var weather = settings.Value` in `MapGet("/weatherforecast")`. Send `GET /weatherforecast?days=8`. `MaxDays` is `7`, and `MinTemperatureC` is `-90`. Step to the `BadRequest` line.
