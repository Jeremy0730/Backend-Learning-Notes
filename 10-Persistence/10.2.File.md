# File

`forecasts.db` is the table. The process can stop. The next run opens that file, and `EnsureCreated` leaves the existing rows in place.

Send the POST from `PersistenceWebApplication.http`. Stop the app. Start it again. Send the GET before sending the POST a second time.

| Step | Result |
| --- | --- |
| `POST` `2026-10-05` with `writer-key` | 201. The project folder contains `forecasts.db` |
| Stop the app and start it | `EnsureCreated` runs. The file is still there |
| `GET /weatherforecast/2026-10-05` before another POST | 200. Temperature is 25 and summary is `Mild` |
| Delete `forecasts.db`, start the app, and GET that date | 404. `EnsureCreated` has made an empty table |

Set a breakpoint on `EnsureCreated`, and another on `FirstOrDefaultAsync` inside `Find`. After the restart, `EnsureCreated` runs once. The GET stops in `Find`. `row` is the forecast from the previous process.
