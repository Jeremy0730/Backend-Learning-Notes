# Throw

`GET /crash` throws `InvalidOperationException`. The lambda does not return a `Results` value.

```csharp
app.Use(async (HttpContext context, RequestDelegate next) =>
{
    try
    {
        await next(context);
    }
    catch (Exception exception)
    {
        app.Logger.LogError(exception, "the request failed.");
        context.Response.StatusCode = StatusCodes.Status500InternalServerError;
        await context.Response.WriteAsJsonAsync(new { error = "the request failed." });
    }
});

app.MapGet("/crash", () =>
{
    throw new InvalidOperationException("the forecast store failed.");
});
```

This `Use` is registered before the routes. `await next(context)` enters the matched lambda. The throw leaves that lambda. The `catch` writes status 500 and a fixed JSON body, then returns. The console log contains `the request failed.` and the exception message `the forecast store failed.` The JSON body does not contain that message.

`GET /weatherforecast?days=2` does not throw. `next` returns the lambda's 200, and the `catch` block does not run.

| Request | Result |
| --- | --- |
| `GET /crash` | 500. Body is `{ "error": "the request failed." }`. The console contains `the forecast store failed.` |
| `GET /weatherforecast?days=2` | 200. The `catch` block does not run. The lambda builds the forecasts |

Set a breakpoint on `throw`, and another on `LogError`. Send `GET /crash`. The throw hits. Continue to the catch. `exception.Message` is `the forecast store failed.`
