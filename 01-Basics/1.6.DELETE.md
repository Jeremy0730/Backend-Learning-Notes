# DELETE

`DELETE /weatherforecast/2026-10-05` removes the forecast stored for that date. The request has no body. The path names the resource.

```csharp
app.MapDelete("/weatherforecast/{date}", (DateOnly date) =>
{
    var removed = forecasts.RemoveAll(item => item.Date == date);
    return removed == 0 ? Results.NotFound() : Results.NoContent();
});
```

`date` is bound from the path before the lambda runs. `RemoveAll` returns how many items it removed. One match returns 204. Zero matches returns 404. `Results.NoContent()` sets 204 and writes an empty body, so the response has no forecast JSON.

`GET /weatherforecast/2026-10-05` after a successful DELETE is 404. `GET /weatherforecast?days=2` still generates forecasts. That route does not read the list.

Send the same DELETE again. The status is 404, and the list is still without that date. The stored result matches the first call. The status is 404 because the forecast is already gone.

| Request | Status | Meaning |
| --- | --- | --- |
| `DELETE /weatherforecast/2026-10-05` after that date was stored | 204 No Content | The forecast is removed. The body is empty |
| `GET /weatherforecast/2026-10-05` after that DELETE | 404 Not Found | That date is not in the list |
| The same DELETE again | 404 Not Found | Still absent |
| `DELETE /weatherforecast/2026-01-01` when that date was never stored | 404 Not Found | The list is unchanged |
| `GET /weatherforecast?days=2` after the DELETE | 200 OK | Generated forecasts. The list is not read |

A later POST for `2026-10-05` stores that date again.

Set a breakpoint on the first line of `MapDelete`. After a POST for `2026-10-05`, send the DELETE. `date` is already `2026-10-05`. Step over `RemoveAll` and inspect `forecasts`: that date is gone. Send the same DELETE again and stop on `NotFound`.
