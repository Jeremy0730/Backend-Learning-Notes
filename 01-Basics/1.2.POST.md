# POST and status codes

`POST /weatherforecast` accepts one forecast in the JSON body and stores it in a list. `GET /weatherforecast/{date}` reads that list. The existing `GET /weatherforecast?days=2` still generates random data and does not use the list.

```csharp
app.MapPost("/weatherforecast", (WeatherForecast forecast) =>
{
    if (forecast.TemperatureC is < -90 or > 60)
        return Results.BadRequest(new { error = "temperatureC must be between -90 and 60." });

    forecasts.RemoveAll(item => item.Date == forecast.Date);
    forecasts.Add(forecast);
    return Results.Created($"/weatherforecast/{forecast.Date:yyyy-MM-dd}", forecast);
});
```

The framework deserializes the body into `WeatherForecast` before the lambda runs. `date`, `temperatureC`, and `summary` come from the JSON. `temperatureF` is calculated and written back in the response.

A status code is the result of the request. The caller branches on that code.

| Request                                                   | Status          | Meaning                                             |
| --------------------------------------------------------- | --------------- | --------------------------------------------------- |
| `POST` with `"temperatureC": 25`                          | 201 Created     | Stored. `Location` is `/weatherforecast/2026-10-05` |
| `POST` with `"temperatureC": 100`                         | 400 Bad Request | Rejected. The list is unchanged                     |
| `GET /weatherforecast/2026-10-05` after a successful POST | 200 OK          | The stored forecast                                 |
| `GET /weatherforecast/2026-01-01`                         | 404 Not Found   | That date is not in the list                        |

Posting the same date again replaces the previous item. The list lives in the process, so stopping the app clears it.

`{date}` is a route value taken from the path. `days` is a query value taken from `?days=2`. Set a breakpoint on the first line of `MapPost`: a valid body shows `TemperatureC` already set, and a temperature of 100 returns 400 before `Add`.
