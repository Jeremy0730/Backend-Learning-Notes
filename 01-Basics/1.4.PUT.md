# PUT

`PUT /weatherforecast/2026-10-05` replaces the forecast already stored for that date. The path names the resource. The body is the whole forecast, not a list of changes.

POST can store a date that was not in the list. PUT cannot. A missing date is 404, and nothing is added.

```csharp
app.MapPut("/weatherforecast/{date}", (DateOnly date, WeatherForecast forecast) =>
{
    if (forecast.Date != date)
        return Results.BadRequest(new { error = "date in the body must match the URL." });

    if (forecast.TemperatureC is < -90 or > 60)
        return Results.BadRequest(new { error = "temperatureC must be between -90 and 60." });

    var index = forecasts.FindIndex(item => item.Date == date);
    if (index < 0)
        return Results.NotFound();

    forecasts[index] = forecast;
    return Results.Ok(forecast);
});
```

`date` is the route value. `forecast` is the body. Both are bound before the lambda runs. A body that fails either check is 400, and the list is not read. `temperatureF` in the JSON is ignored on the way in and calculated on the way out.

`Results.NoContent()` would return 204 and an empty body. This action returns 200 so the caller can see `temperatureF`.

Send the same PUT again. The status is still 200, and the list still holds one forecast for that date. Repeating the call does not add a second copy. That is the idempotent property from the previous lesson, applied to a real route.

| Request | Status | Meaning |
| --- | --- | --- |
| `PUT /weatherforecast/2026-10-05` with a valid body for that date | 200 OK | The stored forecast is replaced |
| The same PUT again | 200 OK | Still one item for that date |
| `PUT /weatherforecast/2026-01-01` when that date was never posted | 404 Not Found | Nothing is added |
| `PUT` with `"temperatureC": 100` | 400 Bad Request | The stored forecast is unchanged |
| Body date `2026-10-06` on URL `2026-10-05` | 400 Bad Request | The stored forecast is unchanged |

PATCH sends only the fields that change, such as `{ "temperatureC": 18 }`, and leaves `summary` as it was. That route is the next lesson.

Set a breakpoint on the first line of `MapPut`. After a POST for `2026-10-05`, send the PUT. `date` is already `2026-10-05`, and `TemperatureC` is already the value from the body. Send the missing-date PUT next and stop on `NotFound` before any `forecasts[index] =` line.
