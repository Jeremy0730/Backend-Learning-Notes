# Filter

`TemperatureFilter` implements `IEndpointFilter`. `InvokeAsync` sees the arguments the framework already bound. A result returned from the filter skips the lambda. `await next(context)` runs the lambda.

```csharp
public async ValueTask<object?> InvokeAsync(EndpointFilterInvocationContext context, EndpointFilterDelegate next)
{
    foreach (var argument in context.Arguments)
    {
        int? temperature = argument switch
        {
            WeatherForecast forecast => forecast.TemperatureC,
            WeatherForecastPatch patch => patch.TemperatureC,
            _ => null
        };

        if (temperature is not int value)
            continue;

        if (value < weather.MinTemperatureC || value > weather.MaxTemperatureC)
        {
            return Results.BadRequest(new
            {
                error = $"temperatureC must be between {weather.MinTemperatureC} and {weather.MaxTemperatureC}."
            });
        }
    }

    return await next(context);
}
```

The constructor takes `IOptions<WeatherSettings>`. The framework runs that constructor for each request that enters the group, then calls `InvokeAsync` on that instance. `weather` is `settings.Value`. The next request constructs another filter and reads the same `WeatherSettings`, because `IOptions<T>` lives for the process, as in `4.1.Options`.

`POST` binds a `WeatherForecast`. A temperature of `100` hits the second `if`. The method returns `BadRequest`. `store.Save` does not run. A temperature of `25` reaches `next`.

`WeatherForecastPatch.TemperatureC` is null when the JSON omits it. That argument continues the loop. `GET` passes `days` and the options object, so the loop calls `next`.

| Request | Result |
| --- | --- |
| `POST` with `"temperatureC": 100` | 400. The list is unchanged. The `MapPost` lambda does not run |
| `GET /weatherforecast/2026-10-05` after that POST | 404. Nothing was stored |
| `POST` with `"temperatureC": 25` | 201. `InvokeAsync` calls `next`, then `store.Save` runs |
| `GET /weatherforecast?days=2` | 200. The filter calls `next`. The lambda builds the forecasts |

Set a breakpoint in the `TemperatureFilter` constructor, and another on `store.Save`. Send the POST with temperature `100`. The constructor runs, then `InvokeAsync` returns 400. `store.Save` does not hit. Send the POST with temperature `25`. The constructor runs again, and `store.Save` hits.
